# plant-identifier

An image-based plant identification application built with Python and TensorFlow.

## Features
- Upload a plant image and get the predicted plant name
- Prediction results displayed in a simple interface

## Tech Stack
Python, TensorFlow, Deep Learning, Image Processing

## Project Details
- Built as a 3-member college team project
- Prepared and processed plant image datasets for model training
- Achieved approximately 98% accuracy during project evaluation
